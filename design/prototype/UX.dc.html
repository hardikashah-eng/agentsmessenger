UX model

Chat is a view. The work object is the substrate.

Object model
Principal
Human, agent or service. Agents act on behalf of a human via scoped, expiring tokens.
Work item
Goal, owner, budget, deadline, participants, artifacts.
Event
Typed: plan, tool call, eval, policy match, human note. Prose is a rendering.
Decision request
The only thing that interrupts a human. Has options and a default.
Policy sits on every event: allow, escalate, hold, or block — before the tool call runs, not after.
Trace keeps every event, signature and token, so any decision can be replayed and bisected.
Five UX principles
01
Attention is the budget
Rank by "only you can decide this". Digest everything else.
02
Every ask is decidable
Evidence, reversibility, blast radius, cost, and what happens if ignored.
03
Provenance is visible
Circles are people, squares are agents, and every agent shows who it acts for.
04
Delegation is a contract
Scope, budget, deadline and escalation, set in one gesture.
05
Autonomy is earned
Tiers move with eval evidence; quarantine is one click.
